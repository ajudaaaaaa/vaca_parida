# Identidade visual rural clássica

Layout inspirado na referência enviada: fundo com textura suave de madeira, área central clara, menu horizontal escuro, verde-sálvia, tipografia editorial condensada e blocos retangulares.

O cadastro de usuários, login, logout e proteções da versão anterior foram preservados.
